# ERP CRM Dashboard

Modern ERP CRM Dashboard uygulaması React, TypeScript ve Tailwind CSS kullanılarak geliştirilmiştir.

## 🚀 Özellikler

- ✅ Responsive Dashboard Layout
- ✅ KPI Cards (Özet Göstergeler)
- ✅ Bar Chart (Aylık Gelir/Gider)
- ✅ Pie Charts (Proje Durumları, Görev Dağılımı)
- ✅ Data Tables (Bekleyen Ödemeler, Aktif Projeler)
- ✅ Sidebar Navigation
- ✅ Modern UI Design

## 📦 Kurulum

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm start
```

Tarayıcınız otomatik olarak http://localhost:3000 adresine açılacak!

## 🛠️ Teknolojiler

- **React 18** - UI Framework
- **TypeScript** - Type Safety
- **Tailwind CSS** - Styling
- **Recharts** - Charts
- **Lucide React** - Icons
